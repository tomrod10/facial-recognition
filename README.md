# facial-recognition


## About
This is a small facial recognition program built in a day using python, OpenCV, Yunet for face detection and Sface for face recognition from opencv_zoo. Most of the code was generated by Google Gemini and the rest was manually done by hand.

## Design Choice
The decision to use OpenCV along with Yunet and Sface was made in the interest of having a lightweight, fast and accurate facial recognition program. The small footprint, low thermals and power necessary to run it makes it ideal for small portable devices like a Raspberry Pi or older devices with limited hardware. In my case, I have a MacBook Air M3 with 24 Gb of RAM which is plenty to run this program. However, given that this is not the only program running on my device, leaving me with 2-3 Gb of free RAM, this program runs and performs very well.

The drawbacks of my design choices are missing out on more complete features from heavier models like, improved occlusion management, detection on smaller faces, handling difficult angles and improved recognition accuracy and more. 

I did try using heavier models with OpenCV on a separate branch but my results were not better than my initial version. More specifically, running the heavier models of RetinaFace for facial detection and ArcFace for facial recognition on my MacBook did not perform well. Frame rate on the live preview were very low making it unusable. The models used on this version were: `retinaface-resnet50.onnx` and `arcfaceresnet100-8.onnx`.

In a last attempt to get another version of the program working I found a lighter versions of the RetinaFace and ArcFace models. ...WIP

## 🚀 Usage
Make sure you have pip installed (version >= 21.x.x)


Just run the following command at the root of the project:
Create python virtual environment
```sh
python -m venv .venv
```

Source the virtual environment
```sh
source .venv/bin/activate
```

Install packages
```sh
pip install -r requirements.txt
```

Run the program
```sh
python app/main.py
```

Note: If it asks for permissions to use your camera, click yes
