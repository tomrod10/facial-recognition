# facial-recognition


## About
This is a small facial recognition program built in a day using python, OpenCV, YuNet for face detection and Sface for face recognition from opencv_zoo. Most of the code was generated by Google Gemini and the rest was manually done by hand 🤌🏼.

## Design Choice
I chose OpenCV alongside YuNet and SFace to build a lightweight, fast, and accurate facial recognition program. Its small footprint, low thermals, and minimal power requirements make it ideal for resource-constrained hardware like a Raspberry Pi. While my MacBook Air M3 has 24 GB of RAM, other active applications leave me with just 2–3 GB of free RAM, yet this setup still performs exceptionally well.

The tradeoff of this lightweight design is missing out on advanced features offered by heavier models, such as better occlusion management, small-face detection, and difficult angle handling. I did test heavier models on a separate branch, but the results did not improve. Specifically, running RetinaFace (retinaface-resnet50.onnx) for detection and ArcFace (arcfaceresnet100-8.onnx) for recognition tanked the live preview frame rate, making it unusable.

In a final attempt, I implemented mobile-optimized versions of RetinaFace and ArcFace (both under 20 MB). Despite being more theoretically capable than YuNet and SFace, these optimized version didn't perform any better from my brief testing. I believe this ultimately stems from my unfamiliarity with these specific models(retinaface_mv2.onnx and (w600k_mbf.onnx).

## E2E
The program can be broken down into two main parts: detection and recognition. For detection, an image is read and key information like its width and height are then passed into the detector (YuNet). Inside the detector a multi-step process occurs:
- Feature extraction: Converts raw pixel data into increasingly useful visual features
- Multi-scale aggregation: Gathers information from the image at different resolutions for the model to detect faces reliably
- Anchor-free heads: Uses feature maps from the CNN backbone to make predictions about potential face locations
- Detection: Produces the face confidence score, bounding box coordinates, and five facial landmarks

Once YuNet provides the bounding box, landmarks, and confidence score, the recognition process begins using SFace. The detected face is first cropped, aligned using the facial landmarks, and scaled into a standardized format. This helps the model process different images of the same person more consistently. 

Once the face has been standardized, SFace processes it into an embedding, which is a numerical representation of the face. This embedding can be stored and later compared against other embeddings to determine facial similarity.

## Usage
Make sure you have pip installed (version >= 21.x.x)


Just run the following command at the root of the project:
Create python virtual environment
```sh
python -m venv .venv
```

Source the virtual environment
```sh
source .venv/bin/activate
```

Install packages
```sh
pip install -r requirements.txt
```

Run the program
```sh
python app/main.py
```

Note: If it asks for permissions to use your camera, click yes
